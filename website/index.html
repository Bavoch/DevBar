DevBar
看看界面如何使用

AI 做好的，随手就能用。

把网站、应用和本地服务，
收进 Mac 菜单栏。

获取 DevBar

项目都在。
终端可以收起来了。

想用哪个，点开就好。
运行、打开、停止，都在这里。

从一个文件夹，
到随时可用。

  1. 加入项目

    点菜单栏中的＋，选中项目文件夹。

  2. 点一下运行

    沿用项目已有的启动方式，入口就绪后自动打开。

  3. 用完就停

    停止运行，项目仍留在列表，下次接着用。

无需账户。
项目和日志，留在本机。

使用 DevBar 无需安装 Node，也无需打开终端。
项目本身需要的运行环境，仍需安装。

从源码安装

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools。v0.16.0 已在 GitHub 开源，正式安装包等待 Apple 签名与公证。

获取 v0.16.0 源码 查看构建步骤
