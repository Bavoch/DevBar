# 公开分发状态

DevBar 按可供其他用户独立安装的 macOS 产品维护。目标用户是使用 AI 构建个人项目的人。

## 已落实到源码

- 单一项目列表；运行、打开、停止为主要操作，技术信息按需查看。
- 普通运行使用项目本地入口，自动适配不猜测安装位置或替换安装版。
- 运行入口统一控制；按具体进程身份和项目归属启停，保护终端、AI 工具与无关服务，支持监督进程异常后的子进程清理。
- 项目配置损坏、重复或记录非法时保留原文件并报错，不崩溃或重置。
- 应用包携带 CLI、驱动和帮助，用户数据独立保存；不依赖维护者源码目录。
- 提供静默隔离回归、macOS CI、签名公证脚本和产物校验值。

## 公开发行前的门槛

| 项目 | 要求 |
| --- | --- |
| 发布身份 | 确定产品所有者、稳定的应用身份、版本与分发渠道 |
| 正式签名 | Developer ID Application 签名，hardened runtime，签名时间戳 |
| 公证 | Apple 公证、装订票据、Gatekeeper 验证 |
| 兼容性 | 在声明支持的 macOS/CPU 上分别验证，不能用本机构建代替 |
| 首次使用 | 干净用户环境验证安装、添加、运行、停止、退出后恢复与升级数据保留 |
| 原生交互 | 人工验收键盘、菜单、长列表及项目编辑；离屏渲染不替代这一步 |
| 帮助与反馈 | 确定支持渠道、安全私密报告入口与源码授权方式；仓库当前无 LICENSE |
| 公开 CI | 首次配置远程仓库后确认 GitHub runner 结果；本地检查不是线上 CI 结果 |
| 扩展平台 | 只发布已完成独立验收的设备/宿主支持范围 |

当前没有把本地临时签名包视为正式发行包，也没有安装、启动或自动升级用户机器中的 DevBar。具体流程见 [发布检查](release.md)，本次审查见 [生产审查](production-review.md)。
